## 🌱 About SeedToServe

**SeedToServe** is a modern farmer-to-customer e-commerce platform designed to help farmers sell their agricultural products directly to customers.

The frontend provides a simple, responsive, and user-friendly experience for both **farmers** and **customers**.

### 🎯 Main Goal

> 🌾 **Empower Farmers**  
> 🛒 **Connect Customers**  
> 🤝 **Enable Direct Selling**  
> 🚜 **Build a Better Agricultural Marketplace**

---

# ✨ Features

## 🧑‍🌾 Farmer Module

- 👤 Farmer registration and login
- 📦 Add agricultural products
- ✏️ Update product information
- 🗑️ Remove products
- 💰 Manage product prices
- 📊 Manage inventory
- 📋 View received orders
- 📦 Manage customer orders
- 🖼️ Upload product images
- 📱 Responsive farmer dashboard

## 🛒 Customer Module

- 👤 Customer registration and login
- 🔐 Secure authentication interface
- 🏪 Browse products from farmers
- 🔍 Search products
- 🏷️ Filter products by category
- ↕️ Sort products
- 📄 View product details
- 🛒 Add products to cart
- ➕ Increase/decrease quantity
- ❌ Remove products from cart
- 💳 Checkout
- 💰 Online payment interface
- 📦 View orders

- 👤 Manage profile
